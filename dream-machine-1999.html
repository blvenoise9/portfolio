Dream Machine 1999 Journal App

An iOS journaling app for capturing life's fleeting moments

Project Overview

DreamMachine 1999 is a personal journaling app I built to capture everyday moments through short notes and photos. Inspired by my own journaling habit, I wanted a simple, private space to record thoughts and memories without the pressure of sharing them on social media.

Unlike traditional journaling apps focused on long entries, DreamMachine 1999 makes it easy to save a photo, a sentence, or a passing thought whenever inspiration strikes.

The name and logo are inspired by Salvador Dalí's The Persistence of Memory, reflecting how quickly moments pass and how memories change over time.

What I Built

I developed a functional journaling app with three main features:

  • Home: View today's journal entry.
  • Add Entry: Write short notes and attach multiple photos.
  • Memories: Browse and revisit previous entries.

The app uses a minimal interface designed for quick journaling, with entries stored locally using LowDB, a lightweight JSON database.

Development

I built the application using React, TypeScript, and Tailwind CSS for the interface, with Node.js, Express, LowDB, and Multer for the backend and image uploads. I also worked with Xcode as part of the iOS development process.

My focus was on keeping the experience simple, with easy navigation, quick entry creation, and local data storage rather than social features.

Next Steps

I plan to refine the iOS experience, improve photo organization, and explore features such as calendar-based browsing and memory reminders.
