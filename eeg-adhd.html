EEG-Based ADHD Classification

Machine Learning for Objective Neurodiagnostics Using Traditional ML Models

Project Overview

ADHD diagnosis relies heavily on behavioral assessments, which can vary between clinicians and patients. This project explored whether machine learning could identify ADHD-related patterns in EEG brain signals to support more objective screening. The project was led as part of a three-person team.

What Was Built

EEG recordings from 121 children aged 7 to 12, including 61 with ADHD and 60 without, were processed using bandpass filtering and Independent Component Analysis (ICA) to remove noise and eye-blink artifacts.

Features including Theta/Beta Ratio, Alpha Power, Slow Wave Activity, and signal complexity were extracted from the recordings. Three machine learning models, Support Vector Machine (SVM), Random Forest, and K-Nearest Neighbors (KNN), were trained and compared.

To ensure reliable evaluation, data was split by participant rather than individual EEG segments, preventing the models from learning patterns specific to children already seen during training.

Results

The best-performing model, SVM using combined EEG features, achieved 76.9% balanced accuracy and an AUC of 0.86. Individual features performed less effectively, with Alpha Power reaching 71% and Theta/Beta Ratio 69% balanced accuracy.

The analysis also revealed a significant risk of data leakage. Randomly splitting EEG segments inflated accuracy to 99%, compared with approximately 74% when participants were kept separate. This highlighted the importance of proper evaluation when working with EEG data.

Impact & Next Steps

The project demonstrated that EEG signals contain useful patterns for distinguishing ADHD and neurotypical groups, while also highlighting how evaluation methods can affect model performance.

Future work includes testing on larger, independent datasets, exploring additional EEG features, and comparing traditional machine learning with deep learning approaches.
