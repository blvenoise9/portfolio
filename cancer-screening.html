Project Type

Public Health Analytics

Tools

Python, Figma

Project Overview

The Cancer Screening Reminder System is a data-driven initiative designed to improve cancer screening rates through personalized reminders based on individual risk factors like age, sex, ethnicity, and family history.

The project focuses on addressing healthcare disparities by prioritizing screening reminders for medically underserved communities, promoting early cancer detection, and improving overall healthcare access.

Key Challenge

How to leverage public health data to create personalized cancer screening reminders that address health disparities and improve early detection rates in underserved populations?

Key Contributions

Analysis

Analyzed California Cancer Registry datasets on cancer incidence by demographic groups to identify patterns and risk factors. Developed logic for personalized screening recommendations based on national guidelines (USPSTF).

UI Foundation

Built the foundation for a user interface that generates age-specific screening reminders.
